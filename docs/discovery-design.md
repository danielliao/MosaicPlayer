# 原生客户端自动发现与选屏

用户目标：安装客户端即可找到后台并选择本机作为第几块屏，不再依赖复制带密钥的播放链接。

实现选择：

1. 原生客户端优先恢复钥匙串中的配对。首次使用按上次服务器、安装包内置服务器地址的顺序尝试；开源构建默认不指定服务器，打包时可通过 MOSAIC_SERVER_URL 配置。
2. 地址不可达时自动进行 Bonjour 服务发现，并对已启用的私有 IPv4 网卡执行有界探测。每块网卡最多探测当前地址所在 /24 与实际子网交集，最多四块网卡、16 并发、单请求短超时；可取消，不进行后台无限扫描。非默认端口通过 Bonjour 或手工地址连接。
3. 用户可手工输入服务器 IP、域名或完整 HTTP(S) 地址。已知旧版设备播放链接仍有效。
4. 独立原生设置窗口列出发现的服务器、后台发布的屏幕编号、行列位置、在线/可用状态；每三秒刷新选中服务器。用户选屏后获取该屏的播放凭据，保存至钥匙串并进入已有同步播放流程。
5. 后台新增持久化发布开关。默认关闭，管理员发布后，局域网客户端才能读取屏幕目录并领取所选屏幕的播放凭据。发现接口不返回管理员密钥、所有屏幕密钥或素材目录。取消发布停止新的自助接入，已配对设备继续播放。
6. 在线屏幕不能被新客户端领取；领取后预留 30 秒，防止同时点击。预留过期可重选；凭据握手后由现有连接状态接管占用显示。旧链接继续兼容其已有连接行为。
7. 连接失效时保留原来的缓存播放与重连，弹出发现窗口供用户选择可达服务器，不静默切换到其他后台。

验证：真实 Node API 检查发布授权、未发布目录、凭据范围、并发领取冲突、在线状态与关闭发布；Swift 检查地址规范化、子网边界、协议验证；真实原生 UI 检查发现、选屏和错误反馈，并运行既有三进程播放回归。实测边界：同机发现与媒体时间不代表另一台 Mac 的权限、组播网络或出光同步已经验收。
