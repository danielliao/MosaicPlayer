# 实现选择

目标：上传一份图片或视频，让多个 Mac 屏幕拼成同一画面并自动同步。当前选择单机 Node.js 服务端 + Web 播放器，不依赖云账号或第三方服务。

服务端：Express 提供管理 API / 媒体 Range 请求；Multer 流式写入本地；ffprobe 校验实际图像或 H.264 MP4；WebSocket 广播布局、时间线和预加载状态。独立管理密钥与屏幕访问密钥隔离写权限。

播放端：大画布 cover 渲染，屏幕通过裁切矩形和逻辑缩放显示自己的区域。时钟估计、短期速率修正、超阈值 seek、断线重连、准备后约定起播。播放静音，避免多设备扬声器叠加。

管理端：总览、素材库、设备状态和网卡选择、规则网格布局、边框补偿。真实状态由服务端提供，不用模拟在线设备或同步指标。

范围：一个播放空间、单素材循环、规则网格、最多 16 屏。暂不包含异形屏自由摆放、异尺寸物理标定、播放列表、定时任务、原生 macOS 屏保、自动开机登录、音频同步、硬件帧锁定。

## 原生播放端扩展（2026-10-20）

现有 Node.js 后台保持管理职责，新增 Swift / AppKit / AVFoundation 独立 macOS 应用，浏览器播放端保留兼容。原生端共享布局与时间线协议，以 AVQueuePlayer / AVPlayerLooper 和 Core Animation 完成播放、缩放与裁切；素材完整缓存后确认就绪。使用 host clock 起播和周期校正，钥匙串保存配对，IOKit 控制播放时的闲置休眠断言。

后台新增 WebSocket Authorization 请求头支持、原生客户端类型上报、原生安装包下载和设备 deep link。默认准备时间扩展到 120 秒，避免完整下载较大素材时过早取消。没有更改素材、设备密钥或持久化状态的存储格式。
