# AI creation, integrations and control

Extend the existing commercial backend, console and Android application; preserve tenant/store authorization and current playback protocol. Development happens in the separate public-source checkout, not in the running private installation. Defaults below are implementation decisions, not previously verified provider/device behavior.

## Features and limits
- Tenant administrators configure their own provider models; platform administrators configure shared models and monthly per-model and per-tenant token budgets. Secrets are encrypted at rest with an installation key stored outside Git; never returned to browsers or logs. Models disabled by default. Server external generation opt-in: COMMERCIAL_AI_ENABLED=true.
- Text/material copy, image, music and video generation are persistent jobs with explicit status, no automatic duplicate paid submissions, monthly UTC budget reservation, prompt limits, bounded downloads, validated media and tenant storage limits. Text actual usage is recorded; media uses configured token-equivalent units per generation, labelled separately from provider tokens. Provider uncertainty consumes reserved units rather than retrying or silently refunding.
- Adapters: OpenAI-compatible chat/completions, images/generations, asynchronous videos; MiniMax music_generation; custom gateway POST /generate with documented JSON contract. Model identifiers are configurable. No real paid requests in tests. Only public HTTPS endpoints by default; installation administrator may explicitly allow exact hosts for internal gateways. Redirects and unsafe addresses rejected.
- Console: models, quotas, AI studio, jobs and importing completed media. Preview uses group layout, program schedule and authenticated media; no device impersonation/heartbeat; actual screenshots remain separately labelled.
- Tenant API keys inherit issuer's live role/store limits, are scoped, expiring, hashed and revocable. Dedicated /api/v1 routes and OpenAPI document. MCP Streamable HTTP 2025-11-25 tools use the same authorization and actions. Cookies remain CSRF-protected; API keys never authenticate ordinary admin/session routes.
- Controller mode within the Android APK: server + scoped API key, authorized groups, buttons and system speech recognition, editable transcript and confirmation. Strict Chinese/English command grammar; unsupported text never causes an action. Device playback key is not a controller key. System recognizer availability and real microphone behavior require device acceptance.
- Chinese/English console and Android controller/core setup strings, persistent locale choice, extensible catalogs. User-entered content is not translated. Document untranslated legacy messages if any.

## Contract
All console requests use existing session/CSRF rules. IDs UUID, dates ISO; camelCase JSON.
GET /api/ai/models -> {enabled, models:[{id,tenantId,name,provider,kind,model,baseUrl,enabled,unitTokens,monthlyTokens,hasSecret}], quotas:[{tenantId,modelId,monthlyTokens}], usage:[{modelId,period,charged,reserved}]}. Tenant responses omit baseUrl for global models. GET/POST /api/ai/models, PUT /api/ai/models/:id. Payload {name,provider,kind,model,baseUrl,apiKey?,enabled,unitTokens,monthlyTokens}; provider enum compatible|minimax|gateway; kind text|image|music|video. Empty apiKey on update preserves existing. DELETE disables, no history deletion.
PUT /api/platform/ai/quotas {tenantId,modelId,monthlyTokens}. GET /api/ai/jobs -> array. POST /api/ai/jobs {modelId,prompt,lyrics?,maxOutputTokens?,requestId} -> job (201; duplicate requestId same job). GET /api/ai/jobs/:id; POST /api/ai/jobs/:id/cancel (queued only). Job {id,modelId,kind,prompt,status,resultText,mediaId,error,chargedTokens,providerTokens,createdAt}. Completed validated media automatically enters media library.
GET /api/integrations/keys -> array. POST {name,scopes:['read','control','ai'],expiresInDays:1..365} -> {key,record}; key shown once. DELETE /api/integrations/keys/:id. Tenant admin only.
GET /api/v1/groups, /api/v1/devices, /api/v1/media, /api/v1/groups/:id/preview; POST /api/v1/groups/:id/control {action:'pause'|'resume'|'play',mediaId?}. Same console preview/control via /api/groups/:id/preview, /api/groups/:id/control. Control respects program limitations: pause/resume only direct media, play uses normal predownload deployment. Response standard group/deployment object; errors {error}. POST /api/v1/ai/jobs, GET /api/v1/ai/jobs/:id. GET /api/v1/openapi.json public schema. Preview {group,media,serverTime}; group camelCase including layout,program,playback; media standard mediaPublic. No device secrets.
POST /mcp: initialize, ping, tools/list, tools/call. Tools mosaic_groups, mosaic_devices, mosaic_media, mosaic_preview(groupId), mosaic_control(groupId,action,mediaId?), mosaic_generate(modelId,prompt,requestId), mosaic_job(jobId). Bearer API key required, same scopes.
