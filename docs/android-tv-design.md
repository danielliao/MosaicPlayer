# Android TV 播放端

原生 Java / Android 界面，Media3 ExoPlayer 硬件视频解码，最低 Android 6.0 / API 23，目标 API 35。交付可侧载的签名 release APK，不依赖 Google Play 服务。同时提供 Leanback 和普通启动入口，适用于支持安装 APK 的小米 Android 电视及电视盒子。

沿用现有后台：内置服务器、记住上次配对、NSD/Bonjour + 有界私有网段探测、手工配置、已发布屏幕目录、空闲屏幕领取、WebSocket 校时与播放状态。播放凭据使用 Android Keystore 加密后保存；后台管理密钥不会进入客户端。

全文件缓存后准备媒体，旧内容保留到新内容就绪与共同时间到达。单调时钟估算服务端时间，跨循环边界计算漂移，微调速率或定位；图片与视频共享虚拟画布裁切及边框补偿。缓存限额 1 GiB，保护当前和准备中的素材，下载校验文件长度并原子落盘。断网继续本地内容，重连追赶时间线。

TV 交互采用可见焦点、方向键、确认和返回键，支持屏幕选择、连接信息、断开、隐藏面板和退出。播放时保持显示屏唤醒，进入后台时停止播放并断开，回到前台恢复配对。未实现系统开机自启或锁屏播放。

验证包括 Java 时钟/几何/协议检查、真实 Node 后台 HTTP/WebSocket/选屏联测、缓存下载检查、Android lint、release 构建及 APK 签名/Manifest 验证。当前没有 ADB 设备和模拟器；硬件视频解码、遥控器实际焦点、电视厂商电源策略及多台电视出光同步须真机验收。
