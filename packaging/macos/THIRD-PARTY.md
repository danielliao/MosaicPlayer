# Bundled runtime

- Node.js 24.14.0: official darwin-arm64 binary; `runtime/node/LICENSE`.
  Download verified against https://nodejs.org/dist/v24.14.0/SHASUMS256.txt.
- PostgreSQL 16.13: PostgreSQL License, built from the unmodified source archive included
  in `sources/`, verified against the official SHA256 file. No ICU/OpenSSL/Homebrew
  libraries are required. Database connections are loopback-only.
  https://ftp.postgresql.org/pub/source/v16.13/
- FFprobe / FFmpeg 8.0.1: LGPL 2.1 or later; no GPL or nonfree options enabled.
  The complete unmodified source archive, license and reproduction script are included.
  This provides the source and build instructions necessary to modify/relink the tool.
  https://ffmpeg.org/releases/ffmpeg-8.0.1.tar.xz
- OpenJDK 17.0.19: trimmed runtime containing java.base and java.logging. See
  `runtime/java/legal` for the GPLv2 with Classpath Exception and third-party notices.
  Source for the corresponding Homebrew OpenJDK distribution:
  https://github.com/openjdk/jdk17u/tree/jdk-17.0.19-ga
  Source archive SHA256: b165f0dd120f4455904b76cf87dd9352fd23f88c2e9a33c2532fabacc3cca962.
  The corresponding unmodified source archive and Homebrew build recipe are included
  in `sources/`. The runtime is generated by jlink; the command is in build-runtime.sh.
- Android Build Tools 35.0.0: aapt, apksigner and C++ runtime.
  See `runtime/android/NOTICE.txt`; signing private keys are not included.
  https://android.googlesource.com/platform/tools/apksig/
  https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/tools/aapt/
- JavaScript dependencies: pinned by `app/package-lock.json`; licenses are retained
  in `app/node_modules`.

The service's native tools are ad-hoc signed after relocation. This package is not
Developer ID signed or notarized. The official Node binary's original signature is
replaced when generating the reproducible relocatable runtime.
